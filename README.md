# Paradise Nursery

Aplikasi toko tanaman daring dengan keranjang belanja.
Dibangun menggunakan React, Redux Toolkit, dan CSS.

## Fitur
- Halaman selamat datang
- Daftar produk dikelompokkan per kategori
- Keranjang belanja: tambah, ubah jumlah, hapus
- Navigasi: Beranda, Tanaman, Keranjang, Tentang Kami

## Teknologi
- React 18
- Redux Toolkit
- React Router
- CSS3
